# ACME Birthday Manager

Учебный Django-проект для практики базовых возможностей фреймворка: Django ORM, ModelForm, class-based views, авторизации, шаблонов и пользовательской валидации.

Приложение позволяет хранить дни рождения, рассчитывать количество дней до ближайшего дня рождения, загружать фотографии, добавлять теги и оставлять поздравления.

## Что реализовано

- модели Django ORM;
- связи `ForeignKey` и `ManyToManyField`;
- формы на основе `ModelForm`;
- пользовательская валидация данных;
- class-based views;
- CRUD для записей о днях рождения;
- регистрация и авторизация пользователей;
- загрузка изображений;
- пагинация;
- Django Admin;
- работа с Django Templates;
- Bootstrap 5;
- пользовательские страницы ошибок 404 и CSRF 403;
- оптимизация запросов через `select_related` и `prefetch_related`.

## Основной функционал

### Дни рождения

Пользователь может:

- добавить человека;
- указать имя, фамилию и дату рождения;
- загрузить фотографию;
- добавить теги;
- просмотреть список записей;
- редактировать и удалять записи.

Для записей действует ограничение уникальности по имени, фамилии и дате рождения.

### Поздравления

Авторизованные пользователи могут оставлять поздравления к записям о днях рождения.

Для каждого поздравления сохраняются:

- текст;
- автор;
- дата создания;
- связанная запись о дне рождения.

### Расчёт даты

Для каждой записи рассчитывается количество дней до следующего дня рождения.

Отдельно обрабатывается случай рождения 29 февраля: если следующий год не високосный, дата переносится на 1 марта.

### Валидация

Дата рождения проходит пользовательскую валидацию.

Допустимый возраст:

- от 1 года;
- до 120 лет.

## Запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/targetfff/acme_project.git
cd acme_project
```

Создайте виртуальное окружение:

```bash
python -m venv .venv
```

Активируйте его.

**Windows:**

```bash
.venv\Scripts\activate
```

**Linux / macOS:**

```bash
source .venv/bin/activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Перейдите в директорию Django-проекта:

```bash
cd acme_project
```

Примените миграции:

```bash
python manage.py migrate
```

Запустите сервер:

```bash
python manage.py runserver
```

После запуска приложение будет доступно по адресу:

```text
http://127.0.0.1:8000/
```
